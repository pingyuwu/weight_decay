机器学习之权重衰减（Weight Decay）深度解读

机器学习之权重衰减（Weight Decay）深度解读

引言

权重衰减（Weight Decay）是机器学习中最基础也最常用的正则化技术。其核心更新公式为：

$$w \leftarrow (1-\eta\lambda)\,w - \eta\,g_{\text{data}}$$

即每一步梯度下降之前，先把权重 $w$ 整体乘以一个略小于 1 的系数 $(1-\eta\lambda)$。这个动作称为"权重衰减"。

但这个公式为何有效？为何"把权重往零拉"就能让模型在新数据上表现更好？本文从机器学习的根本目标出发，经由偏差-方差分解的完整推导，逐步回答这个问题，涵盖损失函数构造、梯度推导、实验验证与优化器实现等环节。

第一部分：机器学习的根本目标与基本假设

1.1 机器学习的根本目标

机器学习目的是通过训练数据对模型进行调优，即尽可能降低训练误差，实现模型在面对训练时未见过的测试数据时表现出尽可能好的准确度，即尽可能降低泛化误差。

这就引出一个核心矛盾：

  • 能够优化的，只有训练误差；
  • 真正在乎的，是泛化误差（新数据上的误差）；
  • 二者并非同一回事。

问题因此变成：凭什么训练误差低，就能相信泛化误差也低？要回答这个问题，必须先弄清训练误差与泛化误差的本质及其相互关系。

1.2 机器学习的基本假设

机器学习理论建立在以下基本假设之上：

假设一：数据生成模型。 真实世界存在一个潜在的规律 $f^*(x)$（例如 $y = 0.05 + 0.01\sum_i x_i$），但观测到的标签带噪声：

$$y^{(i)} = f^*(x^{(i)}) + \epsilon^{(i)}, \qquad \epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2)$$

其中 $f^*(x)$ 是真规律（确定性函数），$\epsilon$ 是噪声（随机扰动）。

假设二：噪声性质。 噪声均值为零、方差为 $\sigma^2$：

$$\mathbb{E}[\epsilon] = 0, \qquad \mathrm{Var}[\epsilon] = \mathbb{E}[\epsilon^2] = \sigma^2$$

假设三：独立性。 噪声 $\epsilon$ 与训练集 $D$ 相互独立——测试点的噪声与训练集如何抽取无关。

1.3 信号、噪声与两类拟合问题

由假设一可知，训练数据里混着两样东西：

  • 真信号 $f^*(x)$：希望学到的普适规律；
  • 噪声 $\epsilon$：每个样本独有的随机扰动，换一份样本就变。

关键麻烦在于：模型分不清这两样东西。对模型而言，$(x^{(i)}, y^{(i)})$ 只是一个数据点，模型只知道"把 $y^{(i)}$ 拟合好"。于是会出现三类情形：

情形一：恰好学到真规律。 模型拟合了真信号 $f^*(x)$，不理会噪声（噪声均值为零，拟合无益）。此时训练误差中等，泛化误差中等，且泛化误差达到理论最低——这是最理想的状态。

情形二：过拟合（overfitting）。 模型过于复杂，不仅拟合了真信号，还把训练集里的噪声 $\epsilon$ 也当成规律背了下来。此时训练误差极低（连噪声都拟合了），但泛化误差很高——因为新数据上的噪声与训练集不同，那套"噪声规律"完全失效，反而拖累预测。

情形三：欠拟合（underfitting）。 模型过于简单，连真信号 $f^*(x)$ 都拟合不全。此时训练误差高，泛化误差也高——模型结构上就表达不了真规律，无论训练数据还是测试数据都表现不好。

1.4 本文聚焦：过拟合

欠拟合的对策相对直接——换用更复杂的模型、增加特征、延长训练即可。而过拟合更为隐蔽且棘手：训练误差低会给人"模型很好"的错觉，实际泛化却很差。更重要的是，过拟合正是正则化技术（包括权重衰减）所要解决的核心问题。

后续内容围绕过拟合展开：先剖析过拟合的数学根源（偏差-方差分解），再说明权重衰减如何作用于这一根源。

第二部分：偏差-方差分解

第一部分厘清了机器学习的基本假设与两类拟合问题。接下来要回答的核心问题是：模型复杂度如何影响泛化误差？过拟合为何在复杂模型中更易出现？

要回答这个问题，需要把泛化误差分解为可解释的组成部分——这就是偏差-方差分解（bias-variance decomposition）。分解之后，便能看清复杂度分别作用于哪一项，从而理解过拟合的机制，也为后续权重衰减的作用点提供依据。

2.1 随机性来源与记号

要分解的量是模型在某个固定测试点 $x$ 上的期望误差：

$$\mathbb{E}\bigl[(\hat{f}(x) - y)^2\bigr]$$

其中期望 $\mathbb{E}[\cdot]$ 对以下两类随机性取值：

  1. 训练集 $D$ 的随机性：训练集是从真实分布中随机抽取的 $n$ 个样本。换一份数据，训出的模型就不同——这是预测 $\hat{f}(x)$ 抖动的来源。
  2. 测试标签的噪声 $\epsilon$：即便固定同一个 $x$，每次观测到的 $y$ 都带一个独立噪声 $\epsilon$。

注意测试点 $x$ 本身是固定的，所有随机性来自上述两类。

为推导方便，引入两个记号：

  • $\hat{f}(x)$：在某个特定训练集 $D$ 上学到的模型在 $x$ 处的预测（随 $D$ 变化，是随机量）；
  • $\bar{f}(x) = \mathbb{E}_D[\hat{f}(x)]$：在"所有可能训练集"上模型的平均预测（这是常数，因为期望已把随机性平均掉了）。

2.2 推导第一步：代入数据生成模型

由 1.2 节假设一，$y = f^*(x) + \epsilon$，代入期望误差：

$$\mathbb{E}\bigl[(\hat{f}(x) - y)^2\bigr] = \mathbb{E}\bigl[(\hat{f}(x) - f^*(x) - \epsilon)^2\bigr]$$

这一步的目的是把"真规律 $f^*(x)$"与"噪声 $\epsilon$"分开——二者在最终公式里地位完全不同（一个进入偏差项、一个进入噪声项），不分开则无法继续推导。

2.3 推导第二步：核心技巧——加减 $\bar{f}(x)$

$\hat{f}(x)$ 是随机的（随训练集变化），其均值未必为零。为了得到干净的分解，在 $\hat{f}(x) - f^*(x) - \epsilon$ 中插入 $+\bar{f}(x) - \bar{f}(x)$（加一个再减一个，值不变）：

$$\hat{f}(x) - f^*(x) - \epsilon = \bigl(\hat{f}(x) - \bar{f}(x)\bigr) + \bigl(\bar{f}(x) - f^*(x)\bigr) - \epsilon$$

这样原式被拆成三块，每块性质截然不同：

  • $\hat{f}(x) - \bar{f}(x)$：随机量，均值为零（因为 $\bar{f}$ 正是 $\hat{f}$ 的均值），物理含义是"这次训练偏离平均训练多少"——对应方差；
  • $\bar{f}(x) - f^*(x)$：常数（与训练集无关），物理含义是"平均模型偏离真规律多少"——对应偏差；
  • $-\epsilon$：随机量，均值为零——对应噪声。

三块中前两块的均值均为零，这正是后续交叉项能消去的根本原因。若不做这个加减 $\bar{f}(x)$ 的技巧，$\hat{f}(x)$ 本身均值未必为零，交叉项消不干净，无法推出干净的三项式。

2.4 推导第三步：展开平方

令 $A = \hat{f}(x) - \bar{f}(x)$，$B = \bar{f}(x) - f^*(x)$，$C = -\epsilon$，则原式为 $\mathbb{E}[(A + B + C)^2]$。展开平方：

$$(A + B + C)^2 = A^2 + B^2 + C^2 + 2AB + 2AC + 2BC$$

展开的目的是利用期望的线性性逐项取期望，从而分辨哪些项保留、哪些项归零。

2.5 推导第四步：逐项取期望

第一项 $A^2$：因为 $A$ 的均值为零，$\mathbb{E}[A^2]$ 即为 $A$ 的方差：

$$\mathbb{E}[A^2] = \mathrm{Var}[\hat{f}(x)] \qquad \text{（方差项）}$$

第二项 $B^2$：$B$ 是常数，期望等于自身：

$$\mathbb{E}[B^2] = (\bar{f}(x) - f^*(x))^2 \qquad \text{（偏差平方项）}$$

第三项 $C^2$：由假设二，$\mathbb{E}[\epsilon^2] = \sigma^2$：

$$\mathbb{E}[C^2] = \sigma^2 \qquad \text{（噪声项）}$$

此处用到 1.2 节假设二：$\mathrm{Var}[\epsilon] = \mathbb{E}[\epsilon^2] - (\mathbb{E}[\epsilon])^2 = \mathbb{E}[\epsilon^2] - 0 = \mathbb{E}[\epsilon^2]$，而 $\mathrm{Var}[\epsilon] = \sigma^2$，故 $\mathbb{E}[\epsilon^2] = \sigma^2$。

第四项 $2AB$：$B$ 为常数，提到期望外：

$$\mathbb{E}[2AB] = 2B\,\mathbb{E}[A] = 2B \cdot 0 = 0$$

因为 $A = \hat{f}(x) - \bar{f}(x)$ 的均值为零（$\bar{f}$ 的定义即 $\hat{f}$ 的均值）。

第五项 $2AC$：由 1.2 节假设三，$A$（依赖训练集）与 $C$（测试噪声）独立，期望可拆开：

$$\mathbb{E}[2AC] = 2\,\mathbb{E}[A]\,\mathbb{E}[C] = 2 \cdot 0 \cdot 0 = 0$$

第六项 $2BC$：$B$ 为常数提到期望外：

$$\mathbb{E}[2BC] = 2B\,\mathbb{E}[C] = 2B \cdot 0 = 0$$

因为 $\mathbb{E}[C] = \mathbb{E}[-\epsilon] = 0$。

2.6 推导收口

六项中只有前三项保留，后三项因含均值为零的随机量而全部归零。于是：

$$\mathbb{E}\bigl[(\hat{f}(x) - y)^2\bigr] = \underbrace{(\bar{f}(x) - f^*(x))^2}_{\text{偏差}^2} + \underbrace{\mathbb{E}\bigl[(\hat{f}(x) - \bar{f}(x))^2\bigr]}_{\text{方差}} + \underbrace{\sigma^2}_{\text{噪声}}$$

即泛化误差 = 偏差平方 + 方差 + 噪声。

2.7 三项的物理意义

  • 偏差平方 $(\bar{f}(x) - f^*(x))^2$：即便把所有可能的训练集都训一遍并取平均，模型仍系统性偏离真规律。这是模型能力不足造成的——结构上就表达不了真规律。简单模型偏差大。
  • 方差 $\mathbb{E}[(\hat{f}(x) - \bar{f}(x))^2]$：单个训练集训出的模型相对平均模型的抖动幅度。这是模型对训练集过度贴合造成的——训练集一变预测就变。复杂模型方差大。
  • 噪声 $\sigma^2$：数据本身的随机扰动，任何模型都无法消除，是误差的地板。

静态图解：偏差-方差四象限靶心图

把上述三项用靶图来直观理解。设想有一个固定的测试点 $x$，靶心代表真规律 $f^*(x)$，每一次用不同训练集训出的模型 $\hat{f}(x)$ 在该点的预测画成靶上的一颗弹孔，所有弹孔的平均位置即 $\bar{f}(x)$（称为准星）。于是：

  • 靶心到准星的距离 = 偏差；
  • 弹孔相对准星的散布范围 = 方差；
  • 靶心本身的抖动 = 噪声（无法在静态图上画出，但它是误差地板）。

依偏差与方差的高低组合，得到四个象限：

象限一：低偏差 / 低方差（理想）。 准星正中靶心，弹孔紧凑地聚在准星周围。此时偏差平方 0.04、方差 0.04、噪声 0.10，总误差 0.18。这是模型复杂度刚好时的状态。

象限二：低偏差 / 高方差（过拟合）。 准星仍在靶心，但弹孔散布很广。此时偏差平方 0.04、方差 0.46、噪声 0.10，总误差 0.60。准星对了，但单次训练都追着各自的噪声跑，预测剧烈抖动。这是复杂模型的典型症状，也是权重衰减要直接打击的一项。

象限三：高偏差 / 低方差（欠拟合）。 弹孔紧凑，但整体偏到一边——准星离靶心很远。此时偏差平方 0.46、方差 0.04、噪声 0.10，总误差 0.60。模型稳定但系统性错位，结构上就够不到真规律。权重衰减治不了这个——它只能压方差，不能补"模型结构本身够不到真规律"的偏差。

象限四：高偏差 / 高方差（最差）。 又偏又散，偏差平方 0.46、方差 0.46、噪声 0.10，总误差 1.02。

关键对照：把象限二和象限一对比看，差距全在方差上——这就是过拟合 = 高方差的字面证据，也是权重衰减唯一能直接缩小的一项。把象限二和象限三对比看，偏差平方和方差互换，总误差一样——说明偏差和方差是两种不同的病，光看总误差分不清是哪种，必须看分解。

2.8 模型复杂度如何影响泛化误差

模型复杂度上升时，三项的变化趋势如下：

  • 太简单的模型：偏差大（表达不了真规律），方差小（连信号都拟合不全，无余力拟合噪声），泛化误差大——此为欠拟合。
  • 复杂度适中的模型：偏差小，方差中等，泛化误差小——此为最优。
  • 太复杂的模型：偏差很小（表达能力强），方差很大，泛化误差大——此为过拟合。

复杂模型方差为何大？因为复杂模型的表达能力强，能拟合任意标签。用训练集 A 训练时，模型把 A 中的噪声 $\epsilon_A$ 也拟合了，预测为真信号加上"对 $\epsilon_A$ 的拟合"；用训练集 B 训练时，模型把 B 中的噪声 $\epsilon_B$ 也拟合了，预测为真信号加上"对 $\epsilon_B$ 的拟合"。但 $\epsilon_A$ 与 $\epsilon_B$ 是独立的随机噪声，拟合出的扰动完全不同，于是两次预测差异很大，方差随之增大。简单模型连真信号都拟合不全，无余力拟合噪声，方差自然小。

过拟合的本质即在此：复杂模型把训练集里的随机噪声也学进去了，而噪声换一份数据就变，导致预测剧烈抖动，泛化变差。

第三部分：治过拟合的三条路

方差大的根源是"模型太复杂、把噪声也学进去"。治法有三条。

路线一：多收数据。 数据增多时，噪声在平均意义下被稀释（大数定律），模型即便想拟合噪声，每条噪声的权重也被摊薄。但数据往往昂贵、耗时或不可控，短期内难以实现。

路线二：降低模型结构复杂度。 例如多项式降阶、神经网络减层。但这条路在高维下过于粗糙：单项式（多项式的高维推广）个数随阶数 $d$ 组合爆炸，$\binom{k-1+d}{k-1}$；"删特征"是 0/1 开关，要么整列保留、要么整列丢弃，缺乏连续调节手段；高维下往往无法判断该删哪个特征。

路线三：限制参数取值范围。 这是权重衰减的入口。思路是不动参数个数，只限制参数能取多大。参数小则函数对输入变化不敏感，不会为追噪声而剧烈扭动，方差随之降低。这条路连续可调，是后续内容的主体。

路线三为何能降低方差，下一部分详述。

第四部分：参数大小与方差的关系

线性模型 $f(x) = w^\top x + b$ 对输入 $x_j$ 的敏感度为 $\partial f / \partial x_j = w_j$：

  • $w_j$ 大，输入 $x_j$ 变化一点，输出就变化很多，对 $x_j$ 极敏感；
  • $w_j$ 小，输入 $x_j$ 变化一点，输出几乎不变，对 $x_j$ 不敏感。

过拟合的本质正是"对输入太敏感"：模型为拟合训练集里的噪声，把某些 $w_j$ 顶得很大，于是输入有一丁点风吹草动（包括新数据中的正常波动），输出就剧烈跳。这种剧烈跳即是高方差。

反过来：把 $w$ 压小，模型对输入不敏感，不会为追噪声而剧烈扭动，预测更稳，方差降低，泛化改善。

由此得到权重衰减的全部物理直觉：过拟合等同于模型对输入过度敏感，等同于权重大；权重衰减把权重压小，等同于降低敏感度，等同于降低方差，等同于治过拟合。

正因为过拟合的根源是模型对输入过度敏感、把训练噪声也学进去，而参数大小直接决定敏感度，且既不能轻易加数据、又不能粗暴删特征，所以需要一个连续可调的旋钮来压低参数大小。权重衰减正是把这个"压参数"的直觉落进优化目标、再求导成"每步乘 $(1-\eta\lambda)$"的那套机制。

第五部分：把"限制参数范围"变成可优化的问题

5.1 罚项登场

优化器只会"最小化一个目标函数"。因此要把"参数要小"这个要求翻译成目标函数里的一项。最自然的度量是 $w$ 离零的距离，即范数 $\|w\|$。但优化中直接用 $\|w\|$ 有麻烦（带根号、$w=0$ 处不可导），改用平方范数 $\|w\|^2$。新目标为：

$$J(w, b) = L(w, b) + \frac{\lambda}{2}\|w\|^2$$

其中 $L(w, b)$ 是拟合数据的损失，$\frac{\lambda}{2}\|w\|^2$ 是惩罚参数大小的罚项。

5.2 损失函数每一项的来历

回到没有正则化的原始损失：

$$L(w, b) = \frac{1}{n}\sum_{i=1}^{n} \frac{1}{2}(w^\top x^{(i)} + b - y^{(i)})^2$$

其中 $\frac{1}{2}$ 与 $\frac{1}{n}$ 都有出处，不是凭空捏造。

$\frac{1}{2}$ 的来源——最大似然。 由 1.2 节假设一，标签服从 $y = w^\top x + b + \epsilon$，$\epsilon \sim \mathcal{N}(0, \sigma^2)$。给定 $x$，$y$ 的条件分布为：

$$p(y \mid x) = \frac{1}{\sqrt{2\pi}\sigma}\exp\!\left(-\frac{(y - w^\top x - b)^2}{2\sigma^2}\right)$$

对数似然为：

$$\log p(y \mid x) = -\frac{1}{2\sigma^2}(y - w^\top x - b)^2 + \mathrm{const}$$

最大化似然等同于最小化 $\frac{1}{2\sigma^2}(y - w^\top x - b)^2$。将 $\frac{1}{\sigma^2}$ 吸收进学习率，剩下 $\frac{1}{2}(\cdot)^2$。所以 $\frac{1}{2}$ 是从高斯噪声假设中自然推出的。

$\frac{1}{n}$ 的来源。 关心的是每个样本的平均损失而非总损失——否则 batch 大则 loss 大，学习率要跟着调。除以 $n$ 把总量变成均值，使超参与 batch 大小解耦。

5.3 罚项中每个符号的来历

为何加进 loss 而非别的形式？ 优化器只会最小化目标函数，加一项是最直接的软约束——不是硬性"参数不能超过某值"，而是"参数越大代价越高"，让优化器自行权衡。

$\lambda$ 是什么？ 权衡旋钮：$\lambda=0$ 时不罚，退回原始过拟合问题；$\lambda \to \infty$ 时只在乎参数小，不学数据，陷入欠拟合；中间的 $\lambda$ 在"拟合数据"与"参数小"之间折中，对应 2.8 节中最优复杂度。

为何 $\lambda$ 要用验证集调？ $\lambda$ 太小治不了过拟合、太大又欠拟合，最优 $\lambda$ 取决于具体数据与噪声水平，理论算不出，只能用验证集试。这正是验证集存在的意义。

为何用 $\frac{1}{2}$？ 求导时 $\frac{d}{dw}\frac{1}{2}w^2 = w$，2 与 $\frac{1}{2}$ 抵消，系数变成干净的 1。

为何用 $\|w\|^2$ 而非 $\|w\|$？ 平方范数去掉了根号，罚项变成各分量平方和，导数为 $\lambda w$，处处可导（包括 $w=0$ 处导数为零）；若用 $\|w\|$，导数为 $\frac{\lambda w}{\|w\|}$，含除法且 $w=0$ 处不可导。

第六部分：求导与更新式

6.1 完整求梯度

对 $J(w,b) = L(w,b) + \frac{\lambda}{2}\|w\|^2$ 求 $w$ 的梯度，分两块。

数据项的梯度。 由链式法则，外层 $\frac{1}{2}(\cdot)^2$ 求导得 $(\cdot)$，内部 $w^\top x^{(i)} + b - y^{(i)}$ 对 $w$ 求导得 $x^{(i)}$，$\frac{1}{2}$ 与求导产生的 2 抵消：

$$\nabla_w L = \frac{1}{n}\sum_{i=1}^n (w^\top x^{(i)} + b - y^{(i)})\, x^{(i)}$$

罚项的梯度。 $\frac{\lambda}{2}\sum_j w_j^2$ 对 $w_j$ 求偏导，2 与 $\frac{1}{2}$ 抵消：

$$\frac{\partial}{\partial w_j}\left[\frac{\lambda}{2}w_j^2\right] = \lambda w_j$$

合起来：

$$\nabla_w J = \frac{1}{n}\sum_{i=1}^n (w^\top x^{(i)} + b - y^{(i)})\, x^{(i)} + \lambda w$$

注意 $\lambda w$ 与数据无关，只与当前权重有关——这正是"每步把权重往零拉"的来源。

6.2 从梯度到 SGD 更新式

SGD 用小批量 $\mathcal{B}$ 近似全样本梯度，步长 $\eta$：

$$w \leftarrow w - \eta\,\nabla_w J$$

代入梯度：

$$w \leftarrow w - \eta\left[\frac{1}{|\mathcal{B}|}\sum_{i\in\mathcal{B}}(w^\top x^{(i)} + b - y^{(i)})\, x^{(i)} + \lambda w\right]$$

把含 $\lambda w$ 的项与左边的 $w$ 合并：

$$w \leftarrow (1-\eta\lambda)\,w - \eta\cdot\frac{1}{|\mathcal{B}|}\sum_{i\in\mathcal{B}}(w^\top x^{(i)} + b - y^{(i)})\, x^{(i)}$$

物理意义至此彻底清楚：每步更新时，先把权重整体乘以略小于 1 的系数 $(1-\eta\lambda)$，再按数据梯度走一步。前一个乘法与数据无关，纯粹是"每走一步之前先缩一下"。"权重衰减"之名正源于此——每步乘以 $(1-\eta\lambda)$ 即衰减。

6.3 衰减因子的量级效应

$(1-\eta\lambda)$ 这一项有多大的"压"力？给一组典型值就有量感。设学习率 $\eta = 0.01$、正则强度 $\lambda = 3$，则每步 $w$ 先乘 $1 - 0.01 \times 3 = 0.97$。这只是 3% 的衰减，看似微不足道；但更新是一步步迭代的，衰减会复利累积。若一轮训练共走 40 步，则 $w$ 总体被乘以 $0.97^{40} \approx 0.29$——即权重被压到原先的三成上下，缩小约 3 倍。这正是"温水煮青蛙"：单步微弱，累计可观。

需要明确一点：上述 $0.97^{40} \approx 0.29$ 只是"纯衰减"的累积。实际更新式是 $w \leftarrow (1-\eta\lambda)w - \eta g_{\text{data}}$，权重还同时受数据梯度推动，不可能精确等于初值乘以 $0.29$。因此这个数字只能作为数量级直觉，用来理解"衰减的累计效果足以显著压低权重"，不能当作精确预测。后续实验中 $\|w\|$ 缩小约 3 至 5 倍，与这个量级直觉相符，可视为对更新式的侧面印证。

6.4 为何罚 $w$ 而不罚 $b$

函数复杂度只来自 $w$，不来自 $b$。$w = 0$、$b = 100$ 的函数是 $f(x) \equiv 100$，是常数函数，与 $b = 0$ 一样简单——对输入没有任何"扭曲"反应。决定函数扭来扭去的是 $w$：$w$ 大则输入 $x$ 的微小变化被放大成输出的剧烈变化，这才叫"复杂"。

正则的目标是限制"对输入的敏感度"，而 $b$ 只是全局平移，不影响敏感度，罚它无意义，还会把截距硬拉向零，伤害带非零均值的目标。因此本文及主流实现中的罚项只作用于 $w$，$b$ 不参与。

6.5 小结：权重衰减的完整公式链条

到此，从"模型对输入太敏感 → 把权重压小"这一直觉出发，已经推出可执行的更新式：损失函数加 $\frac{\lambda}{2}\|w\|^2$ 罚项，对 $w$ 求梯度得 $\lambda w$，与 SGD 合并得每步先乘 $(1-\eta\lambda)$ 再走数据梯度。这套机制已经完整、可落地。

接下来用一个具体实验验证这套机制是否真的按预期工作：不加正则时是否过拟合、加正则后 $\|w\|$ 是否被压小、验证误差是否下降。

第七部分：实验验证

7.1 为何需要实验

至此已从理论上推出：$\lambda = 0$ 时无正则、应过拟合；$\lambda > 0$ 时权重被持续衰减、应缓解过拟合。但理论只是预期，还要用一次具体实验来检验这套机制是否真的按预期工作。实验要回答三个问题：① 不加正则时，是否真出现过拟合（训练误差低、验证误差高）？② 加正则后，权重 $\|w\|$ 是否真的被压小？③ 压小后，验证误差是否真的下降？

7.2 完整实验代码

为让效果足够显眼，构造一个故意刁难的设定：真值模型为

$$y = 0.05 + \sum_{i=1}^{d} 0.01\,x_i + \epsilon,\qquad \epsilon \sim \mathcal{N}(0,\, 0.01^2)$$

把维度拉到 $d = 200$，训练集只有 20 个样本。200 维乘以 20 样本是典型的"参数远多于数据"的过拟合温床。

下面给出完整可运行的 PyTorch 代码，包括数据生成、线性模型、训练循环、评估以及 $\|w\|$ 的记录：

import torch
import torch.nn as nn

# ---- 超参数 ----
n_train, n_val = 20, 100          # 训练 20 个样本，验证 100 个样本
dim = 200                          # 输入维度 200
true_w = torch.full((dim, 1), 0.01)  # 真值权重全为 0.01
true_b = 0.05                      # 真值偏置
num_epochs = 100
batch_size = 5
lr = 0.01                          # 学习率

# ---- 生成数据 ----
torch.manual_seed(1)
def synthetic_data(n):
    X = torch.randn(n, dim)
    y = X @ true_w + true_b + torch.randn(n, 1) * 0.01
    return X, y

X_train, y_train = synthetic_data(n_train)
X_val, y_val = synthetic_data(n_val)

# ---- 线性模型 ----
class LinearReg(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.w = nn.Parameter(torch.randn(dim, 1) * 0.01)  # 小随机初始化
        self.b = nn.Parameter(torch.zeros(1))
    def forward(self, x):
        return x @ self.w + self.b

def train(weight_decay):
    """weight_decay 即 λ，传入 SGD 的 weight_decay 参数"""
    model = LinearReg(dim)
    optimizer = torch.optim.SGD(model.parameters(), lr=lr, weight_decay=weight_decay)
    loss_fn = nn.MSELoss()
    for epoch in range(num_epochs):
        # 小批量训练
        for i in range(0, n_train, batch_size):
            Xb = X_train[i:i+batch_size]
            yb = y_train[i:i+batch_size]
            optimizer.zero_grad()
            loss = loss_fn(model(Xb), yb)
            loss.backward()
            optimizer.step()
    # 训练结束后评估
    with torch.no_grad():
        train_loss = loss_fn(model(X_train), y_train).item()
        val_loss = loss_fn(model(X_val), y_val).item()
        w_norm = model.w.norm().item()
    return train_loss, val_loss, w_norm

# ---- 对比 λ=0 与 λ=3 ----
for lam in [0, 3]:
    tr, va, wn = train(lam)
    print(f"λ={lam:>2} | train_loss={tr:.4f} | val_loss={va:.4f} | ||w||={wn:.4f}")

这段代码中，weight_decay 参数直接传入 torch.optim.SGD，由优化器在更新阶段对权重施加 $(1-\eta\cdot\mathrm{wd})$ 的衰减。在 SGD 下，这等价于在 loss 中加 $\frac{\lambda}{2}\|w\|^2$ 罚项。

7.3 实验结果与解读

运行上述代码，得到如下对比（数值会因随机种子略有波动）：

  • $\lambda = 0$（不加正则）：训练误差降到接近零，验证误差约为 $0.038$——典型过拟合。$\|w\|_2$ 约为 $0.137$，权重被推得很大以拟合训练集噪声。
  • $\lambda = 3$（加正则）：训练误差略有上升，但验证误差降到约 $0.020$。$\|w\|_2$ 降到约 $0.035$，比 $\lambda=0$ 时小了约 4 倍。

这里需要注意：训练共走了 $20/5 \times 100 = 400$ 步。若只看纯衰减，$0.97^{400} \approx 5 \times 10^{-6}$，权重应几乎被压到零；但实测 $\|w\|$ 仍有 $0.035$。这正说明 6.3 节的限定——纯衰减只是近似，实际权重同时受数据梯度推动，梯度与衰减达到平衡后稳定在一个非零值。$\lambda=0$ 与 $\lambda=3$ 的 $\|w\|$ 比值约为 4 倍，与"衰减显著压低权重"的定性结论一致。

7.4 对照解读

把 $\lambda = 0$ 与 $\lambda = 3$ 并排看：

  • $\lambda = 0$：$\|w\|_2 \approx 0.137$、验证误差约 $0.038$，过拟合。权重未被压，模型尽情把 200 维里的噪声都拟合了，到验证集上全失效。
  • $\lambda = 3$：$\|w\|_2 \approx 0.035$（小约 4 倍）、验证误差约 $0.020$，正则生效。权重被压小，模型对输入敏感度降低，无法追着噪声跑，泛化更稳。

静态图解：调节 λ 的权衡过程

为更直观地看到权重衰减"用偏差换方差"的权衡，下面把第二部分中"低偏差 / 高方差"那个过拟合靶单独拿出来，按 $\lambda$ 由 0 增大到 1，看偏差平方、方差、总误差三项如何此消彼长。三项满足一个简化模型：

$$\text{偏差}^2(\lambda) = 0.04 + 0.42\,\lambda^2, \qquad \text{方差}(\lambda) = 0.04 + 0.42\,(1-\lambda)^2, \qquad \text{噪声} = 0.10$$

总误差为三项之和。下面列出三个关键 $\lambda$ 取值：

关键点一：$\lambda = 0$（起点，过拟合）。 偏差平方 0.04、方差 0.46、噪声 0.10，总误差 0.60。靶图上：准星在靶心（偏差小），弹孔散得很开（方差大）。这是无正则的原始状态——模型尽情追噪声，方差被顶起来，对应 7.3 节的实验。

关键点二：$\lambda = 0.5$（最优）。 偏差平方 0.145、方差 0.145、噪声 0.10，总误差 0.39。靶图上：弹孔收拢（方差下降），准星略微偏离靶心（偏差略升），但二者接近平衡。这是权重衰减该停的位置——靠验证集找到它。总误差 0.39 是这条 U 形曲线的最低点。

关键点三：$\lambda = 1$（终点，欠拟合）。 偏差平方 0.46、方差 0.04、噪声 0.10，总误差 0.60。靶图上：弹孔聚成一团（方差极小），但整体偏到右下（偏差很大）。$\lambda$ 太大，把权重压死，模型连真信号都表达不了。

总误差随 $\lambda$ 的 U 形曲线。 把上面三个点连起来，加上中间取值，可看出总误差随 $\lambda$ 呈 U 形：$\lambda=0$ 时 0.60，$\lambda=0.5$ 时 0.39（最低），$\lambda=1$ 时 0.60。这就是"用偏差换方差"权衡的几何表达——$\lambda$ 太小治不了方差，$\lambda$ 太大又把偏差顶起来，最低点在中间，靠验证集调参找到它。

这个静态过程同时讲清三件事：权重衰减改的是哪一项（主要变的是方差条与弹孔散布，对应第二部分偏差-方差分解里的方差项）；为何有最优 $\lambda$（总误差是 U 形，最低点在中间）；"用偏差换方差"的字面含义（偏差平方条由短变长、方差条由长变短，二者此消彼长）。

至此，理论与实验闭环。下一部分跳出"自己写罚项"的实现方式，看主流深度学习框架是如何把同一机制内置进优化器的。

第八部分：与优化器内置 weight_decay 的等价

8.1 为何改由优化器实现

前文一直在 loss 里手动加 $\frac{\lambda}{2}\|w\|^2$ 罚项，再走 SGD。这种写法概念清晰，但工程上每写一次模型都要自己拼罚项、自己处理梯度，繁琐易错。于是主流框架把它做成优化器的一个参数，让用户只需声明"我要做权重衰减"，框架自动在更新阶段完成。本部分说明：在 SGD 下，这种"框架内置"与"loss 手动加罚"二者数学等价，只是实现位置不同。

把 6.2 节的更新式再写一遍：

$$w \leftarrow w - \eta\lambda w - \eta\cdot g_{\text{data}}$$

可以看出，更新式中"衰减"这一动作完全由 $\eta\lambda$ 这个乘积决定。因此优化器只需把这个乘积作为一个参数暴露给用户，即可在更新阶段直接完成衰减，无需用户在 loss 里手动加罚项。这个参数就是 weight_decay：它等于 $\eta\lambda$，即学习率与正则强度的乘积。

PyTorch 原生写法如下（weight_decay=3 即取 $\eta\lambda = 0.01 \times 3 = 0.03$，与 6.3 节的设定一致）：

optimizer = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=3)

在 SGD 下，loss 加罚项与优化器内置 weight_decay 二者数学等价（同一组梯度代数），只是实现位置不同：前者在 loss，后者在 optimizer。第七部分的实验代码正是采用了优化器内置的写法。

8.2 AdamW 的区别

事情到了 Adam 这里就变了。Adam 先对梯度做动量与二阶矩归一化，再施加更新。若把 $\ell_2$ 罚项加进 loss，罚项的梯度 $\lambda w$ 会与数据梯度一起被 Adam 的归一化处理（除以了二阶矩的平方根），不再是干净的按比例缩放——$(1-\eta\lambda)$ 那一干净的衰减语义被破坏了。

AdamW 把衰减解耦出来：权重衰减单独施加在不被归一化的 $w$ 上，恢复了"纯 $(1-\eta\lambda)$ 衰减"的语义。这就是 AdamW 在深度学习中几乎取代"Adam 加 $\ell_2$"的原因——它让权重衰减在自适应优化器下仍保持 SGD 时那种干净行为。

这一部分的要义是：权重衰减的本质不在"它写在 loss 还是 optimizer"，而在"是否真正实现了 $(1-\eta\lambda)$ 这一纯衰减"。SGD 下两种写法都对；Adam 下只有解耦写法才对。

第九部分：延伸——$\ell_2$ 与 $\ell_1$ 的对比

前文讲的权重衰减对应的是 $\ell_2$ 正则。$\ell_1$ 正则是另一类方法，它也能限制权重，但会把部分权重压到零，产生稀疏解。若只关心权重衰减本身，可跳过本节；本节作为延伸阅读，说明 $\ell_2$ 与 $\ell_1$ 的区别，以及为何权重衰减默认选 $\ell_2$。

9.1 记号约定

第六部分把罚项写成 $\frac{\lambda}{2}\|w\|^2$，这是 $\ell_2$ 范数的平方。"参数离零多远"这件事并非只有一种度量方式，另一种常见度量是 $\ell_1$ 范数。约定记号：

$$\|w\|_2 = \sqrt{\sum_j w_j^2}, \qquad \|w\|_1 = \sum_j |w_j|$$

本文的 $\ell_2$ 罚项写作 $\frac{\lambda}{2}\|w\|_2^2$（为简洁常省略下标 2，记为 $\|w\|^2$）；$\ell_1$ 罚项写作 $\lambda\|w\|_1$。两者都衡量"$w$ 离零多远"，但几何与代数性质迥异，由此带来截然不同的稀疏行为。

9.2 几何路：约束区域形状决定切点位置

将目标改写为等价的约束形式（拉格朗日对偶直觉）：

  • $\ell_2$ 版：$\min_w L(w)$，约束 $\|w\|_2 \leq R$，约束区域是球；
  • $\ell_1$ 版：$\min_w L(w)$，约束 $\|w\|_1 \leq R$，约束区域是菱形（顶点在坐标轴上）。

最优解在"损失等高线（椭圆）与约束区域的切点"处。关键差别在于切点落在哪里：

  • 与球相切，椭圆几乎只能在球的鼓出方向上碰到球，而球鼓出的方向对应各分量比较均匀的点，故所有分量都不为零且大小相近；
  • 与菱形相切，菱形的鼓出集中在顶点（顶点是最远点），椭圆容易正好顶到某个顶点上，顶点意味着只有一个分量非零、其余全为零，故稀疏。

$\ell_1$ 天然做特征选择而 $\ell_2$ 不行的几何原因即在此——并非罚项数值大小的问题，而是约束区域几何形状的问题。

9.3 解析路：$\ell_1$ 在零处不可导

直接看 $w_j = 0$ 这个点：

  • $\ell_2$ 罚项 $\frac{\lambda}{2}w_j^2$ 在零处可导，导数正好为零。数据梯度推 $w_j$ 离开零一点点，$w_j$ 就跟着离开零，没有"卡在零点"的效应。
  • $\ell_1$ 罚项 $\lambda|w_j|$ 在零处不可导，其次梯度是区间 $[-\lambda, \lambda]$。只要数据梯度推 $w_j$ 离开零的力小于 $\lambda$，就存在 $[-\lambda, \lambda]$ 里的值与之抵消，使零仍是稳定点，该分量被压在零，等于被"剪掉"。

$\ell_1$ 的稀疏性来自"零是不可导点加上次梯度是个区间"，$\ell_2$ 没有这个性质。这是比几何更本质的解释。

9.4 为何权重衰减默认用 $\ell_2$ 而非 $\ell_1$

本文及绝大多数权重衰减实现选用 $\ell_2$，理由有三：其一，$\ell_2$ 罚项处处可导，SGD 更新式能干净地拆出 $(1-\eta\lambda)$ 这一衰减因子（见 6.2 节），数值稳定；其二，$\ell_2$ 倾向把权重均匀摊到更多特征上，对单个变量的测量误差更鲁棒，适合"全部特征都有用、只是要防过拟合"的常规场景；其三，$\ell_2$ 与主流深度学习优化器（SGD、AdamW）的接口天然契合。

$\ell_1$ 则在"很多特征实际无用、需要自动挑出少数有用者"时才更有优势——它在统计学习里以套索回归（lasso）闻名，与 $\ell_2$ 的岭回归（ridge）并列。一句话：权重衰减是 $\ell_2$ 这一具体选择，而 $\ell_1$ 是它的近亲，二者的对比帮助我们看清 $\ell_2$ 为何"压而不剪"。

第十部分：完整逻辑链收口

至此全文走完。把各部分串成一条因果链，只回顾前文已建立的结论，不引入新概念：

  1. 目标（第一部分）：要的是泛化好，而非训练好；训练误差低不保证泛化好。
  2. 病根（第二部分）：复杂模型把训练集里的噪声也学进去，噪声换一份数据就变，预测剧烈抖动，方差大——这就是过拟合，由偏差-方差分解严格揭示。
  3. 治法选择（第三、四部分）：加数据太贵、删特征太钝；而参数大小直接决定模型对输入的敏感度，压小参数即降低敏感度、降低方差，故限制参数大小是连续可调的治过拟合之路。
  4. 落地（第五、六部分）：把"参数要小"翻译成 loss 里加 $\frac{\lambda}{2}\|w\|^2$ 罚项，$\lambda$ 用验证集调；求梯度得 $\lambda w$，与 SGD 合并推出每步先乘 $(1-\eta\lambda)$ 再走数据梯度，即"衰减"的字面含义；只罚 $w$ 不罚 $b$，因复杂度只来自 $w$。
  5. 验证（第七部分）：完整可运行代码显示，$\lambda = 0$ 时 $\|w\| \approx 0.137$、验证误差高（过拟合）；$\lambda = 3$ 时 $\|w\| \approx 0.035$（小约 4 倍）、验证误差显著下降（正则生效）。纯衰减近似与实测的差异说明数据梯度同样在起作用。
  6. 工程实现（第八部分）：SGD 下优化器的 weight_decay 参数等于 $\eta\lambda$，与 loss 加罚项数学等价；Adam 下必须解耦（即 AdamW）才能保住 $(1-\eta\lambda)$ 的纯衰减语义。
  7. 延伸（第九部分）：权重衰减默认是 $\ell_2$ 正则，"压而不剪"；$\ell_1$ 正则会把部分权重压到零、产生稀疏，适用于特征选择场景。

回到最初的问题——为何"把权重往零拉"就能让模型在新数据上表现更好？答案是：过拟合的根源是模型对输入过度敏感、把训练噪声也学进去；参数大小直接决定敏感度。既不能轻易加数据、又不能粗暴删特征，因此需要一个连续可调的旋钮来压低参数大小，从而压低方差、治过拟合。权重衰减就是把这个"压参数"的直觉落进优化目标、再求导成"每步乘 $(1-\eta\lambda)$"的那套机制。

后记：从权重衰减看正则化思想

权重衰减不是孤立的技术，而是后续几乎所有深度学习正则化方法的思想原型：

  • Dropout：每次随机丢弃一部分神经元，本质也是降低模型对单个特征的过度依赖，从而降方差。
  • Early Stopping：在训练误差还没降到最低时停下，本质是限制参数离开初始值的距离，与 $\ell_2$ 正则在某些条件下等价。
  • 数据增强：人为扩充训练数据多样性，从"加数据"那条路治过拟合。
  • Batch Normalization：通过限制激活分布的偏移，间接起到轻微正则化作用。

这些方法手段各异，但共享同一个底层逻辑：限制模型对训练数据偶然性的过度贴合，换取对新数据更稳健的泛化。理解了权重衰减这条完整的推导链，再去看这些后续方法，就不会觉得它们是零散的技巧，而是同一思想在不同场景的变奏。
